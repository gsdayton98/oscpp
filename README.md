# oscpp
C++ wrapper around operating system-specific utilities

|                 |                                                                                      |
|-----------------|--------------------------------------------------------------------------------------|
| test            | Unit test routines for each function.                                                |
| circular_buffer | Double ended queue using a static array, and<br/>wrap-around.                        |
| dynamiclibrary  | Get information about a dynamically loaded library.                                  |
| file            | File utilities.                                                                      |
| file_descriptor | File descriptor utilities.                                                           |
| random_device   | Provide a default wrapper of system random device.                                   |
| socket          | Socket utilities.                                                                    |
| stopwatch       | Stopwatch class for timing sections of code.                                         |                                                           
| sysexception    | Exception class for system errors. Extracts error message associed with an errno,    |
| trim            | Trim whitespace from a string.                                                       |
